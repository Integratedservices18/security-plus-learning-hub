# 🔐 Security+ Interactive Learning Hub

An interactive learning platform I built to master CompTIA Security+ (SY0-701) concepts using a structured, hands-on approach.

## 📌 Overview
This project organizes Security+ topics into:
- Domain-based learning (aligned with exam objectives)
- Interactive lessons and flashcards
- Scenario-based PBQ (Performance-Based Questions) practice
- Real-world mapping to datacenter operations

## 🎯 Purpose
- Prepare for CompTIA Security+
- Reinforce cybersecurity fundamentals
- Bridge datacenter operations with security concepts
- Serve as a structured learning system and portfolio project

## 🧠 Key Features
- ✅ 5 Security+ domains with breakdowns and examples
- ✅ Incident Response and Threat Mitigation scenarios
- ✅ Interactive quiz system
- ✅ Flashcards for rapid memorization (CIA, AAA, IAM, etc.)
- ✅ Ports & Protocols reference (exam-focused)
- ✅ Study tracker and roadmap
- ✅ Real-world cybersecurity mapping to operations

## 🛠 Technologies Used
- React
- Tailwind CSS
- Recharts (data visualization)
- Framer Motion (UI animations)

## 📊 Security+ Domains Covered
1. General Security Concepts
2. Threats, Vulnerabilities, and Mitigations
3. Security Architecture
4. Security Operations
5. Governance, Risk, and Compliance (GRC)
